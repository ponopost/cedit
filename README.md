# cedit

- NES-style Pixel Art & Character Editor (HTML5 Canvas)
- ファミコン風ドット絵・キャラクターエディタ

## 機能
- **2色描画（MacPaint風）**: タッチ・クリックで「色1」「色2」をスマートに切り替えて描画・消去
- **タブレット・タッチ対応**: 指での操作に対応
- **キーボード操作**: `WASD` キーでマップ側の選択エリア移動
- **変形機能**: 上下左右スクロール、左右反転、上下反転、90度回転
- **ファイル入出力**: NES ROM（BG/SP）読み込み、PNGダウンロード対応
- 編集中は**ブラウザのローカルストレージ**に自動保存されるのでリロードなどで消える心配がありません

## 使い方
1. [GitHub cedit Pages](https://ponopost.github.io/cedit/cedit.html) にアクセスします。
2. 画面上のパレットで色1・色2を選択し、ドットを描画します。
